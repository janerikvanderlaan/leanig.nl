# Leanig logos

Logo concepts made in October 2026. Concept B (dark version) is the logo on leanig.nl.

| File | What it is |
| --- | --- |
| `b-obeya-logo.svg` | Concept B (Obeya grid), for light backgrounds |
| `b-obeya-logo-dark.svg` | Concept B, for dark backgrounds (used on the site) |
| `a-flow-logo.svg` | Concept A (Flow), for light backgrounds |
| `a-flow-logo-dark.svg` | Concept A, for dark backgrounds |
| `*-mark.svg` | The symbol on its own |
| `*-icon.svg` | The symbol on a dark rounded tile, for favicons and app icons |

Colours: deep `#0f3d4a`, teal `#1f7a86`, yellow `#f2c230`, soft `#cfe6e9`. The LEANIG lettering is drawn as rounded strokes, so no font is needed.
